## rgctl v0.4.17

Tier 1 **Kotlin**, **Groovy**, and **Puppet**; AST coverage manifests as the language-support SSOT; TS/JS named arrows; config/Kantra ingest hardening; docs and README refresh.

```bash
rgctl --version
rgctl discover . -l kotlin,groovy,puppet --with-cfg
rgctl -f json gql 'MATCH (n:Function) RETURN n LIMIT 10'
```

## Highlights

### New Tier 1 languages

- **Kotlin** (`rgctl-lang-kotlin`, `tree-sitter-kotlin-ng`) — `.kt` / `.kts` (except Gradle basename routing to Manifest extractors).
- **Groovy** (`rgctl-lang-groovy`) — `.groovy` / `.gradle`.
- **Puppet** (`rgctl-lang-puppet`) — `.pp`, with CFG hosts for class/define/node.
- Ecommerce fixtures, GQL smoke scripts, dashboard gates, and Gate B cold-profile hooks where corpora exist.
- Merged via [#99](https://github.com/sshaaf/rgctl/pull/99).

### AST coverage SSOT

- Every Tier 1 (+ markdown) plugin ships `{id}-ast-coverage.json` (named kind → handler).
- `rgctl-ast-coverage` + `rgctl-languages` `build.rs` warn on grammar drift (`RGCTL_AST_COVERAGE_STRICT=1` fails).
- Website `/docs/languages/` is generated from those JSON files at build time; hand-written `docs/languages/*.md` guides retired.

### Config / Kantra / ingest

- Exclusive ingest routing for build manifests; real dependency nodes; span-faithful config keys; Java/C# → config links; Kantra providers use those nodes without dual-emitting config soup (Gate A preserved).

### TypeScript / JavaScript (#96 / #98)

- **Named arrows** — `const` / `let` / object-property / class-field arrows and function expressions name from their binding (no single `anonymous` per file). Unnamed callbacks use `anonymous@L{line}`. **Rediscover** TS/JS repos after upgrade.
- CFG skip diagnostics summarized by reason; community flat-graph UX warning; discover `--exclude` repeatable; release checksum packaging hardened.

### Docs / website

- README rewritten for first-time visitors (try path + marketing badges).
- [Introduction](../Introduction.md) updated for current CLI surface and language SSOT.
- Agent-first docs hub pointers refreshed.
